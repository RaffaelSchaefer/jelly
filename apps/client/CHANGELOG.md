# Changelog

Was sich für alle mit Jelly ändert, neueste Version oben. Der Update-Hinweis der App zeigt die
Abschnitte seit der installierten Version (`src/pet/changelog.ts`), zugeklappt die ersten drei
Zeilen. Je Version eine Überschrift `## X.Y.Z` wie in `tauri.conf.json`, darunter kurze Zeilen mit
`Neu:`, `Besser:` oder `Weg:`, je höchstens etwa 40 Zeichen, damit sie in eine Zeile der Karte
passen. Ohne Abschnitt für die Version bricht das Release ab.
